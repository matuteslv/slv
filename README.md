# slv

Configuración de Claude Code para este repo.

## Qué se instala solo al abrir una sesión

`.claude/settings.json` activa el catálogo oficial de plugins y estos 6 plugins:
frontend-design, code-review, code-simplifier, chrome-devtools-mcp, figma y vercel.

`.claude/skills/10k-websites/` trae la habilidad para armar sitios web con video que avanza al hacer scroll.

## Instalar en una PC con Windows

Entrá a `instalador-windows/` y hacé doble clic en `INSTALAR.bat`. En `LEEME.md` está el detalle de cada plugin y habilidad.
